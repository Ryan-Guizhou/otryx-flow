# 非功能需求 NFR（Proposed）

| ID | 类别 | 最低可验证约束 | 验证入口 |
|---|---|---|---|
| NFR-001 | 安全 | HTTPS、项目 RBAC、生产 mTLS/证书绑定/方法授权；公网不执行自定义代码 | AT-11, AT-16 |
| NFR-002 | 正确性 | 唯一逻辑火点、Outbox/Inbox 幂等、Lease/Fencing，清楚声明至少一次语义 | AT-07, AT-08, AT-09 |
| NFR-003 | 伸缩 | 多 Scheduler、Dispatcher 和 Worker 同时在线；工作分配有界 | AT-07, AT-13 |
| NFR-004 | 可观测 | runId/attemptId/traceId 关联，任务积压、租约与 RPC 失败分类可查 | AT-12 |
| NFR-005 | 审计 | 发布、删除、重试、取消、权限修改有 Actor 与原因；禁止修改历史 | AT-02, AT-12 |
| NFR-006 | 部署 | 干净环境可复现部署、健康检查、回滚与备份恢复 | AT-01, AT-14, AT-15 |
| NFR-007 | 性能 | 固定环境记录吞吐/p50/p95/p99、队列延迟、GC/CPU/内存、积压和错误；门槛在 M5 前冻结 | AT-13 |
| NFR-008 | 兼容 | API schema、Worker SDK、RPC contract 有版本策略并覆盖 N/N+1 和回滚 | AT-14 |
| NFR-009 | 前端 | 支持键盘导航、错误反馈、时区展示和国际化基础；以 WCAG 2.2 AA 为目标 | AT-03, AT-05 |
| NFR-010 | 隐私 | 凭证不入日志、项目隔离、存储保留/清理策略、导出审计 | AT-02, AT-12 |

**SLO 冻结规则**：M0 不伪造绝对容量指标。M4 评估典型任务类别（无 IO、轻 IO、慢 IO），M5 在固定硬件与版本签字预声明目标后才将阈值转换为不可豁免门禁。Demo 单节点不承诺多机房高可用。
